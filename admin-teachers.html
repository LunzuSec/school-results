Define the CA items for each class+subject+term. Teachers enter scores against these items in the teacher portal. Weights apply when combining CA and exam scores.



How CA works: For each subject, define one or more CA items (e.g. Test 1, Test 2, Assignment). Teachers enter raw scores against each item. The final subject score combines CA and exam per the weights above. If no CA is entered for a subject, the exam score is used as the final (or CA counts as zero, depending on the fallback rule).
